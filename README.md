# Quiz Website

Eine interaktive Quiz-Anwendung, entwickelt mit **HTML**, **CSS** und **JavaScript**. Nutzer können Fragen beantworten und ihre Ergebnisse direkt anzeigen lassen.

## Features

* Mehrere Quizfragen
* Sofortige Auswertung der Antworten
* Punkteanzeige am Ende des Quiz
* Benutzerfreundliches und responsives Design
* Dynamische Inhalte mit JavaScript

## Verwendete Technologien

* HTML5
* CSS3
* JavaScript

## Installation

1. Repository klonen:

```bash
git clone https://github.com/dein-benutzername/dein-repository.git
```

2. Projektordner öffnen

3. `index.html` im Browser starten
